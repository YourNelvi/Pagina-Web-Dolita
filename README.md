# Dolita Web

Página web oficial de Dolita — Cotizaciones del dólar en Venezuela.

## Stack

- Angular 19
- Tailwind CSS (CDN)
- TypeScript

## Desarrollo

```bash
cd dolita-web
npm install
npm start
```

Abre http://localhost:4200

## Despliegue

El proyecto se despliega automáticamente en Vercel al hacer push a `main`.

## APIs

- **Dólar API**: https://ve.dolarapi.com/v1/dolares
- **Binance P2P**: API de Binance para USDT/VES
